# 言情写作要点

- **关系是主线**：每章都要让两人的关系发生一点变化，靠近、试探、误解或后退。原地踏步的甜也会腻。
- **拉扯要有内因**：阻碍来自两人的性格、处境、过去的伤和互相的误读，少用偶然和第三者硬拆。
- **把心动写在细节里**：记住对方的小习惯，下意识的动作，一句话里的停顿。少直接写“心跳加速”“脸红”。
- **双方都要有主体性**：女主和男主都有自己的事业、朋友和选择，不围着对方打转。
- **情绪要有落点**：甜要甜得具体，虐要虐得有理由，和解要有实际行动，不靠一句对不起。
- **配角推动感情线**：闺蜜、家人、前任、对手的介入要带来关系的新局面。
- **爽点类型**：撑腰护短、误会解开、公开关系、对手认输、事业高光，配合情感高点使用。
