# 都市写作要点

- **现实感是底牌**：职业细节、城市生活、钱和人情的算计要准，读者会拿自己的生活对照。金额、流程、行业术语要合理。
- **快节奏**：冲突要早、要近，三五句话内进入矛盾。场景以对话和交锋为主，少写内心独白。
- **打脸要有铺垫**：让对手的轻视具体可见，反转时用证据、资源或人脉，一击致命。旁观者的反应要写够。
- **关系网是戏眼**：家人、同事、前任、合伙人都带着利益和感情，同一个人可以既帮你又坑你。
- **爽点类型**：身份反转、商业翻盘、专业碾压、护短撑腰、亲情和解，轮换使用。
- **主角要有清晰的事业目标**，阶段性可见可量化：第一单、第一家店、上市、收购。
- **对白口语化**：符合年龄和职业，带点当下的说话方式，但少用会迅速过时的网络梗。
