# 科幻写作要点

- **一个核心设定，推到极致**：想清楚一条“如果”，再追问它对社会、权力、家庭和个人的后果。设定服务于戏，戏反过来逼出设定的新面向。
- **规则先立后用**：世界规则写进 `bible/world/rules.yaml`，主角破局必须在规则内。伏笔式的规则铺垫能带来最好的智识爽感。
- **技术解释要短**：用人物的使用场景和误操作来讲设定，一次一点。说明文式的段落一律拆进情节。
- **尺度感**：大场面靠小人物的视角落地，宇宙尺度也要有具体的人在受苦、在选择。
- **解谜节奏**：线索 → 假设 → 证伪 → 新线索，让读者跟着推理，并且偶尔能赢过主角。
- **爽点类型**：技术破局、规则反杀、认知颠覆、绝境求生、文明级抉择，轮换使用。
