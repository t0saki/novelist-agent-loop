# 长篇网文工艺（通用）

目标读者是手机上追更的人：一章读三分钟，随时可能划走，也随时可能打赏。一切手法都服务于“让他点下一章”。

## 黄金三章
- 第一章：一百字内进入事件，亮出主角的处境和特质，抛出一个他必须解决的困境。不写世界观开场，不写起床、回忆、天气。
- 第二章：主角动手，兑现第一个小爽点，让读者看清这本书的卖点是什么。
- 第三章：抬高赌注，亮出更大的目标或对手，章末留下让人想追下去的钩子。
- 设定在冲突中顺手带出，用到才讲，一次只讲一点。
- 前三章每一章都要回答读者心里的问题：“这人凭什么值得看？”

## 爽点节奏
- 爽点是“压抑 → 反转 → 兑现 → 旁人反应”的完整回路。压得不够，爽感不足；兑现不写透，等于没爽；旁人的反应是爽感的放大器，要具体，别千篇一律。
- 小爽点每章都要有（小胜、打脸、得到、被认可），中爽点三到五章一次，大高潮一弧一次。
- 爽点要换类型：实力碾压、智谋翻盘、身份揭晓、情感兑现、资源收获、复仇得报。连着用同一种，读者会腻。
- 主角的胜利要靠自己的选择和付出的代价，不能只靠运气或别人施舍。
- 憋屈可以有，但不要隔夜：一段压抑最多跨几章，就要给出路或给希望。

## 钩子
- 每章结尾停在未解决的瞬间：新危机、新信息、一个两难选择、一个反转、一句话的余音。不写总结，不抒情升华。
- 章内也要有小悬念：开头埋一个问题，中段回答它并抛出新问题，让读者一路有事等。
- 钩子要兑现。连续用虚假悬念（“他看到了……”下一章什么都没有）会消耗读者的信任。
- 换着用：悬念钩、危机钩、期待钩（马上要打脸）、情感钩、信息钩。

## 伏笔回收
- 一条伏笔要经历“埋设 → 提醒 → 回收”。埋设时自然，读者不觉得是伏笔；回收时让人觉得“原来早有线索”。
- 长线伏笔隔几十章提醒一次，换个角度，让读者记得。
- 回收要带来情节后果，不只是解释一句。严格按章卡的 `pays`、`advances` 执行，不要自行开新线。

## 人物弧光
- 主角有明确的缺陷和渴望，成长要付出真实代价；一路顺风的主角没人关心。
- 配角有自己的目的，不是主角的工具人；反派有逻辑、有手段，不降智。
- 人物变化由事件逼出来，体现在选择上，而不是靠旁白宣布“他变了”。
- 对白要有区分度：遮住人名也能听出是谁在说话。

## 场景与信息
- 每个场景都要回答：谁想要什么？什么挡着他？结束时局面变了什么？
- 控制信息差：让读者比角色多知道一点（紧张），或比角色少知道一点（好奇），不要同步平铺。
- 进场晚，出场早：跳过寒暄和走路，直接进入有戏的部分。

## 去 AI 味
- 用细节代替形容：不写“他很愤怒”，写他把茶杯搁在桌上时杯底碎了。
- 避开模板句：“不是……而是……”“仿佛……一般”、三连排比、段尾的感慨和升华。
- 少用万能动作（点头、深吸一口气、沉默片刻）和万能表情（嘴角上扬、眼中闪过）。
- 允许不工整：句子长短参差，有口语、有留白，有角色的偏见和废话。
- 别替读者总结，别解释刚刚写过的情绪，别把潜台词说破。

## 结构纪律
- 每章都要有变化：局面、关系或信息至少一项不同。没有变化的章节不要写。
- 不注水：不复述上一章，不长篇回忆，不大段描写和情节无关的风景。
