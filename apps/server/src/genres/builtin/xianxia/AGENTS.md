# 仙侠写作要点

- **修炼是主线的发动机**：每次突破都要有代价和阻碍（资源、心魔、劫难、对手截胡），不写“闭关三月，水到渠成”。
- **境界体系守规矩**：严格按 `bible/world/rules.yaml`。越级取胜必须有明确的底牌和代价，事后要有后果。
- **资源与因果**：丹药、法宝、机缘都要写清来路和代价；得到的东西后面要用上。因果和人情是长线伏笔的好材料。
- **地图升级**：村镇 → 宗门 → 州郡 → 大陆 → 上界，每次换舞台都换规则、换对手、换利益格局。旧地图的人物隔一段回来，能制造“故人重逢”的情绪。
- **宗门是社会**：师徒、同门竞争、长老派系、资源分配，用这些造冲突，比单纯打怪更耐读。
- **斗法要有构思**：写清法术特点、环境利用、以弱胜强的计算。不要纯比数值，不要大段招式名。
- **东方气质**：用词简净，有山水、有道心、有世情冷暖。修行之余留一点人间烟火，反差才动人。
- **爽点类型**：扮猪吃虎、拍卖捡漏、大比夺魁、秘境奇遇、宗门打脸、师门护短、复仇清算，轮换使用。
