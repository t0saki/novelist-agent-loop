# 任务单

任务：开书，并写完整本（约 4 章）

这是一本新书。主人的种子在 seed.md（原样保留，可能为空）。

1. 先读 seed.md 和下面的书库摘要。想 3 个不同的方向，选和书库里已有的书最不像的那个，在 bible.md 里写一行"与《X》《Y》的区别"。
2. 写 bible.md：第一行"# 《书名》"，第二行"一句话：……"，第三行"标签：……"（3–6 个词）；然后写人物、世界、文风和结局。
3. 写 outline.md：全书骨架（写明结局）、一行"计划：共 N 章"（建议 4 章，最多 8 章）和每一章的细纲。
4. 然后直接写正文，从第 1 章写到最后一章：manuscript/c00001.md、manuscript/c00002.md……每个文件第一行写"# 第N章 章名"，每章一次写成。
5. 全书写完后写 notes/progress.md：写到第几章、一段前情提要、还有什么没收尾。
6. 全书不少于 15000 字，每章不少于 3000 字，不设上限。
7. 最后一章写完后，在末尾单独一行写"（全书完）"。

书库摘要（不要和这些书雷同）：
- 《雨夜来客》：一个邮差在暴雨夜收到寄给自己的信。
- 《无名之书》

省事的规矩：
- 不用自己统计字数，系统会统计；不要重读自己刚写的文件。
- 写的时候就注意：每章结尾是完整的句子；正文里没有"（本章完）"、创作说明或写给读者以外的话；少用重复的词、说明腔和设问式的结尾。
- bible.md 前三行按上面的格式写。
